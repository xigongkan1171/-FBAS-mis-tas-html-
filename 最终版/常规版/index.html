02 术语速查

这些是连段/指令解说里常见的简写，主要用于描述输入方式、取消关系和招式类型。

术语含义说明
F帧1/60 秒，游戏内最小时间单位
JJump，跳跃常用于跳入、空中动作
~目押 / 非取消连接表示不是取消，要按时机连接
>、→取消连接包含除派生取消外的一切取消
>>派生连接招式派生到下一段
·顺序输入按顺序依次输入，不可同时按
xn乘以 n表示重复 n 次
()备注补充说明用
(n)命中 n 段例如 0 表示不中或挥空
PPunch，拳泛指轻拳、中拳、重拳等
KKick，踢泛指轻脚、中脚、重脚等
CHCounter-Hit破招、打康
GBGuard-Break破防
GPGuard-Point架招、防护点
{x}里取消x 为普通技
[]前提条件方括号内是不在连段里显示的条件
DC发动模式中的任意取消模式中可用的取消
SC超级取消Special / Super Cancel 语境下使用
GC防御取消有回避和反击两种，常写 GCAB / GCCD
Q 发动快速发动地面普通技或特殊技命中按 BC
Q 回避快速回避地面普通技或特殊技命中按 AB
MacroLua 语法速查

一行通常写成“指令 + 帧数 + 逗号”，例如 (d.)1,。括号里是该帧输入，点号 . 表示和下一帧分隔。

符号含义备注
U / D / L / R上 / 下 / 左 / 右本工具快捷键会写入 u/d/l/r
1 / 2 / 3 / 4A / B / C / D基础攻击键
S / `Start / Select系统按键
C / @ / ~Coin / Test / Reset@ 可进入 BIOS
$1 / &1存档 1 / 读档 1数字可换成其他槽位
< / / / >P1 开始 / P2 开始 / 结束用于区分玩家指令段
#注释# 后面的内容不识别为玩家指令
(...)n循环例如 (...)3 表示循环 3 次
Wn等待 n 帧例如 W60 表示等待 60 帧
.分隔符分隔上一帧和下一帧
 
&1

...
